## 先明确目标与边界

目标是无付费模型接口、允许慢速、逐镜审片。**没有保证本机模型达到参考样片画质。** 增加等待时间能缓解显存不足，却不能无限提升模型的脸部一致性、复杂动作和细节能力。本工作台是本地逐镜素材生成入口，不是已验收的一键周更成片系统。

Toonflow 官方 README 中的约130元，是其约两分钟示范作品调用语言/图片/视频模型的费用，并不是软件每生成一条视频统一收费。该示例用的是 Claude Opus 4.6、GPT Image 2、Seedance 2.0，不能把其效果直接归因于开源前端。

## 一、先用已接好的本机工作台

在项目根目录用 PowerShell：

```powershell
cd E:\AI漫剧\ai-comic-drama
.\scripts\start_local_free.ps1 -StartComfy -Background
```

打开 `http://127.0.0.1:18766/`。此脚本不安装依赖、不下载模型、不设置开机自启，不关闭其他程序。端口仅绑定 `127.0.0.1`，不要开放到公网。

只检查环境：

```powershell
.\scripts\start_local_free.ps1 -CheckOnly
```

不启动 Comfy，仅前台运行网关（便于观察错误，Ctrl+C 结束网关，不中断 Comfy 正在执行的任务）：

```powershell
.\scripts\start_local_free.ps1
```

| 环节 | 实际本地后端 | 限制 |
| --- | --- | --- |
| 剧本/提示词草案 | Ollama `qwen2.5:7b`，CPU，4096上下文，最多2048输出token，生成后卸载 | 需人工编辑，不能保证多镜复杂剧本正确 |
| 文生图 | RealVisXL V5，40步 | 720×1280 / 1280×720 / 1024×1024；不支持参考图锁脸或图像编辑 |
| 单首帧图生视频 | Wan2.1 I2V 14B FP8，20步，37层交换 | 原生480×832、8fps、17/25/33帧；近似竖屏，无音轨 |
| TTS/口型/剪辑成片 | 未包含在新网关中 | 不会自动调用旧 SadTalker/SAPI/Kokoro 或付费接口 |

视频选项“2/3/4秒”表示首末帧采样跨度；MP4按8fps编码17/25/33帧，容器时长通常为2.125/3.125/4.125秒。480×832不是精确9:16；本阶段保留原生画面，不偷偷拉伸或标成1080p。后期放大不能恢复模型没有生成的细节。

操作顺序：先写草案 → 生成静帧 → 审核五官、衣服、手部、背景 → 选中合格首帧 → 一个镜头只描述一个主要动作 → 生成短片 → 逐帧审片 → 合格后才继续后续镜头。走路、打斗等必须单独验收，不能以一次转头成功代替。

## 二、对接当前 Toonflow

媒体设置中添加自定义供应商，导入：

```text
integrations/toonflow/localFreeV2.ts
```

它使用当前 `export default / generateImage / generateVideo` 协议，固定连接本机18766，不要填API Key。供应商仅含上述图片和视频能力。旧 `localWanComfy.ts` 仅适用于旧接口，不能导入 Toonflow 2.x，现已退出当前公开版本；见[旧适配器退役说明](LEGACY_TOONFLOW.md)。

供应商的参考图支持base64/二进制；URL只能来自本机 Toonflow 默认3000端口或网关18766端口，不跟随重定向。多参考图、尾帧、参考视频、配音和不支持的高清参数会明确报错，不静默忽略。取消 Toonflow 的等待不等于取消 GPU 任务，重新提交前先看本机队列，防止重复。

语言模型在 Toonflow 内单独添加自定义供应商：

- 地址：`http://127.0.0.1:11434/v1`
- 协议：`openai-completions`
- API Key：留空
- 模型 ID：`qwen2.5:7b`
- 上下文：先设4096，最大输出2048，避免未知模型默认超大上下文

注意：直接连接 Ollama 的 Toonflow 请求**不受新网关强制 CPU 的参数约束**。先完成文本工作再生成图片/视频，不要同时加载多个模型争抢8GB显存。若要确保文本只用CPU，请使用18766工作台的文本入口。本轮未对完整 Toonflow 的代理工具调用流程做端到端验收；7B模型未必能可靠执行所有复杂工具调用。

Toonflow 中不要选 TF-Router 等云端供应商。“仅本地”的承诺适用于这里的新网关和导入的本地媒体供应商，不是对所有历史脚本、其他软件或系统网络的防火墙封锁。当前 Toonflow 设置保存是完整覆盖；不要用一个配置片段直接覆盖原有设置。

## 三、任务保存与失败处理

- 任务元数据、首帧和最终产物位于 `runtime_cache/local_free_jobs`。
- Comfy 输出另存于 `runtime_cache/comfy_output/local_free`，日志在 `logs`。
- 每个任务保存种子、工作流、模型文件名、实际分辨率和 Comfy prompt ID；大视频不塞进JSON。
- 元数据原子替换；新网关内单worker串行执行图片/视频。不要同时用其他入口提交GPU任务。
- 网关重启时，已保存prompt ID的任务会查询Comfy历史/队列，不重新生成。
- 提交已发出但未拿到确认，或Comfy重启后丢失任务时，标为 `needs_attention` 并暂停队列。绝不自动重交以掩盖未知结果。需人工核对Comfy日志与输出后处理，当前不提供一键盲重试。
- 内存门禁是预检，不是OOM不会发生的保证。关闭不用的软件后再检查；不要为了绕过报错随意关门禁。

API：`GET /health`、`GET /jobs`、`GET /jobs/{id}`、`GET /jobs/{id}/asset`、`POST /text`、`POST /jobs/image`、`POST /jobs/video`。接口详情见本机 `/docs`。

## 四、质量与商用验收

“接口返回成功”只代表文件生成与结构检查通过，不代表脸部/动作达到样片。至少检查：

1. 原始分辨率看眼睛、嘴、头发、服装和背景细节；不能只看缩略图。
2. 首、中、尾帧身份一致；逐帧排查变脸、穿模、多手、闪烁。
3. 实际播放动作连贯，脚步有落点、接触关系合理，不能用静帧推拉代替人物动作。
4. 跨镜头角色、道具和光线一致；固定种子本身不能保证角色一致。
5. 核对素材权利记录：[COMMERCIAL_RIGHTS_LEDGER.md](COMMERCIAL_RIGHTS_LEDGER.md)。软件MIT、模型免费、能生成文件，都不等于整片的声音、肖像、角色、音乐和字体自动获得商用授权。

不达标的素材保留为测试结果，不命名“最终成片”。如果本地模型反复无法通过短镜头验收，就明确记录能力上限，不以“再慢一点”保证必然成功。
