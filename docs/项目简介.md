# 项目简介

## 背景

短剧/漫剧制作常见路径依赖按次计费的云端模型 API，成本高、素材与提示词外流风险大。**镜语 · JingYu** 把「可运行的本机生成网关」做成开源工程：文本草案、静帧、短动态镜头在本地闭环，由人审片与剪辑，而不是宣称替代整套商业制片流水线。

## 定位

| 是 | 不是 |
|:---|:---|
| Windows + NVIDIA 上的本地生成网关与逐镜工作台 | 一键精品短剧成品 |
| 队列可恢复、失败可解释、内存会拒绝 | 静默重试到“看起来成功” |
| 可选 Toonflow 媒体供应商适配 | 完整 Toonflow 应用本体 |
| Apache-2.0 自有代码 + 第三方权利台账 | 模型权重与成片的一揽子商用授权 |

## 核心链路

1. **Ollama** `qwen2.5:7b`：剧本/提示词草案（CPU）  
2. **RealVisXL V5**：静帧（人审）  
3. **Wan2.1 I2V 14B FP8**：单首帧短视频（人审）  
4. **网关队列**：JSON 落盘、进程锁、重启接管、`needs_attention`

## 适用场景

- 本机实验漫剧/短剧分镜与短镜头试拍  
- 不想把草稿提示词送到按次收费 API 的创作流程  
- 需要可审计队列与诚实失败语义的二次开发  

## 明确不适用

- 无人值守批量出片并保证商用画质  
- 无 NVIDIA / 无大内存环境下的“同等效果”承诺  
- 把开发机未打包的 Comfy 补丁当成上游默认能力
